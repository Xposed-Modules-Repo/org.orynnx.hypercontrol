# HyperControl

HyperControl is a libxposed API 102 module for Xiaomi HyperOS Control Center.

Features:

- Swap the media playback block with the brightness and volume controls.
- Render brightness and volume as horizontal controls with left-aligned icons.
- Material 3 settings screen and verified SystemUI restart handling.

Source code and documentation: https://github.com/Orynnx/HyperControl

The release was built with `:app:assembleRelease` and `:app:lintRelease`, and verified on Nubia NX667J / HyperOS Android 14 / LSPosed API 102.
